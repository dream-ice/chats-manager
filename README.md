# Chats Manager

一个融入 SillyTavern 角色管理页的聊天整理插件。

## 功能

- 角色页只保留 **Characters** 与 **Chats** 两个原生风格标签。
- Chats 按角色自动收纳；没有内部聊天分组时直接平铺展示。
- 进入角色聊天后自动切换为当前角色专注视图，也可随时返回全部角色总览。
- 每个角色内部可创建独立分组。
- 同一套分组和父子分支树会同步显示在 SillyTavern 原生“管理聊天记录”窗口中，不影响原生搜索、重命名、导出和删除操作。
- 原生聊天管理器提供批量管理模式，可全选当前搜索结果、批量移动分组、导出 JSONL/TXT 或统一确认删除。
- Chats 页面同样支持新聊天、指定角色导入、打开原生管理器、单聊导出/删除，以及跨角色批量收藏、分组、导出和删除。
- 每条聊天提供独立的备份按钮；点击后在 Chats 原位置进入该聊天的备份历史，并可一键返回聊天列表，不额外增加全局备份标签或管理弹窗。
- 单聊备份页按备份时间直接平铺，顶部提供关键词搜索、翻页、每页数量、刷新和批量管理；不再套用聊天分组或折叠层级。
- 预览默认显示开头 5 楼与结尾 5 楼，可分别选择 3/5/10/20 楼；通过文件头尾分段读取控制内存，不会为预览把超大备份完整载入浏览器。
- 单聊备份支持原始下载、恢复为新聊天、单个或批量删除，也可全选当前页并打包下载；批量 ZIP 上限为 256 MiB。
- 每条聊天只常驻重命名按钮，其余操作收纳在省略号菜单中；顶部铅笔按钮可切换批量编辑模式。
- 可收藏具体聊天；收藏项会跨角色复制到列表顶部的快捷区，原聊天仍保留在原角色、分组和时间位置。
- 收藏快捷区可独立展开或折叠。
- 角色可按最近聊天、角色名称或聊天数量排序，并选择每页显示 10/20/30/50 个角色。
- 默认先用轻量索引显示聊天名称，再逐个角色在后台补充分支、楼层数和末条预览；大型聊天不会再阻塞整个列表。
- 单角色聊天总量超过 256 MiB 或 80 个文件时保持轻量模式，不自动扫描完整详情；用户可在明确的内存风险提示后手动加载。
- 当前角色模式只读取当前角色，全部列表只按需处理当前页；收藏角色会额外补载，避免角色和聊天很多时一次性扫描全部文件。
- 读取 SillyTavern 原生 `chat_metadata.main_chat`，将分支聊天附着在父聊天下方，并用连接线与“分支”标记显示层级。
- 支持搜索角色名、聊天名与最后一条消息。
- 支持移动和重命名聊天；创建分组入口位于“移动到分组”弹窗中。
- 使用角色头像文件名作为稳定键，降低角色 ID 变化造成的整理数据错位。

## 与 ChatsPlus 一起使用

Chats Manager 能在首次加载时接管 ChatsPlus 已移动的角色列表，但建议在扩展设置中关闭 ChatsPlus，避免两个插件同时请求和刷新聊天数据。

## 数据

收藏、分组、排序、分页数量和折叠状态保存在 SillyTavern 的 `extension_settings.chatsManager` 中；删除分组不会删除聊天文件。插件启用后直接生效，不额外创建扩展设置抽屉。

搜索聊天名/消息或选择“聊天数量”排序时，为保证结果完整，插件会按最多 4 个并发请求建立全库索引；之后会复用会话缓存，手动刷新时才重新读取。

聊天备份目录只会在用户主动点击某条聊天的备份按钮时读取，并且只继续识别该角色的备份。恢复操作始终导入为一份新聊天，不会覆盖现有聊天。
