# Chats Manager

由 **icedream** 开发的 SillyTavern 第三方扩展，用更接近酒馆原生界面的方式整理大量角色聊天。

## 功能

- 在角色侧栏提供 **Characters / Chats** 双标签。
- 按角色收纳聊天；无内部分组时保持平铺。
- 进入聊天后自动聚焦当前角色，也可返回全部角色总览。
- 支持角色内聊天分组，分组同步投影到原生“管理聊天记录”窗口。
- 识别 `chat_metadata.main_chat`，以树形连接线显示父聊天和多级分支。
- 跨角色收藏聊天，在顶部生成可折叠的快捷区，不改变原聊天位置。
- 原生聊天管理器支持批量移动分组、导出 JSONL/TXT 和删除。
- Chats 页面支持新聊天、指定角色导入，以及单聊导出、删除、重命名、分组和收藏。
- 除重命名外的单聊操作统一收进省略号菜单；顶部铅笔按钮可批量收藏、分组、导出和删除。
- 支持最近聊天、角色名称、聊天数量排序与角色分页。
- 先用轻量索引显示聊天名称，再以最多 2 个并发任务在后台补充分支、楼层数和末条预览，大型聊天不会阻塞整个列表。
- 当前角色、当前页和收藏角色按需加载；请求超时或异常时会降级显示基础列表并提供重试。
- 兼容桌面端与移动端触控滚动。
- 自动隐藏父文件已不存在的无效“回到父级聊天”按钮。

## 安装

在 SillyTavern 中打开：

`扩展 → 安装扩展 → 输入 Git 仓库 URL`

粘贴：

```text
https://github.com/dream-ice/chats-manager
```

安装完成后刷新 SillyTavern。插件默认启用，不会额外创建设置抽屉。

## 使用说明

- 点击聊天右侧省略号可收藏、分组、导出或删除；原聊天仍保留在角色和分组中的原位置。
- “移动到分组”弹窗可新建分组；移动父聊天时会整理整棵父子聊天树。
- 当前打开角色聊天时，Chats 页面会进入当前角色模式；工具栏可切回全部角色。
- Chats 页顶部铅笔按钮可进入跨角色批量管理模式。
- 原生“管理聊天记录”窗口中的“批量管理”支持选择当前搜索结果后统一操作。
- 搜索聊天名或消息、以及选择“聊天数量”排序时，会先显示轻量索引结果，再在后台逐步补全预览信息。

## ChatsPlus 兼容性

Chats Manager 可以接管 ChatsPlus 已移动的角色列表，但建议只启用其中一个扩展，避免重复请求和刷新角色数据。

## 数据与隐私

- 分组、收藏、排序、分页和折叠状态仅保存在 SillyTavern 的 `extension_settings.chatsManager` 中。
- 扩展只调用当前 SillyTavern 实例的本地接口，不上传角色卡、聊天内容或设置到第三方服务。
- 删除分组不会删除聊天文件；批量删除聊天前会再次确认。
